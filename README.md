# 🏡 House Price Prediction

## 📌 Proje Hakkında

Bu projede, Kaggle House Prices veri seti kullanılarak ev fiyatlarını tahmin eden bir makine öğrenmesi modeli geliştirilmiştir.

Proje; veri analizi, feature engineering, eksik veri işlemleri, model karşılaştırmaları ve hiperparametre optimizasyonu adımlarını kapsamaktadır.

---

## 🎯 Projenin Amacı

Ev fiyatlarını mümkün olan en düşük hata oranıyla tahmin eden bir regresyon modeli geliştirmek.

---

## 📂 Veri Seti

Bu proje Kaggle'daki **House Prices: Advanced Regression Techniques** yarışmasının veri seti kullanılarak hazırlanmıştır.

Veri setinde;

- Ev özellikleri
- Yapım yılı
- Oda sayıları
- Arsa bilgileri
- Garaj
- Bodrum
- Dış cephe özellikleri
- Satış fiyatı

gibi çok sayıda değişken bulunmaktadır.

---

## ⚙️ Projede Yapılan İşlemler

- Keşifsel Veri Analizi (EDA)
- Eksik Veri Analizi
- Aykırı Değer Analizi
- Rare Encoding
- Feature Engineering
- Label Encoding
- One-Hot Encoding

---

## 🤖 Kullanılan Regresyon Modelleri

- Linear Regression
- KNN Regressor
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor
- XGBoost Regressor
- LightGBM Regressor

---

## 🔧 Model Optimizasyonu

Model performansını artırmak amacıyla GridSearchCV ile hiperparametre optimizasyonu uygulanmıştır.

---

## 📊 Model Değerlendirme

Performans değerlendirmesinde aşağıdaki metrik kullanılmıştır.

- RMSE (Root Mean Squared Error)

Ayrıca log dönüşümü uygulanarak model başarısı karşılaştırılmıştır.

---

## 📈 Feature Importance

LightGBM modeli kullanılarak değişken önem sıralaması oluşturulmuştur.

---

## 🏆 Kaggle

Model kullanılarak test veri seti tahmin edilmiş ve Kaggle formatında submission dosyası hazırlanmıştır.
